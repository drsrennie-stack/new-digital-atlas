ANATOMY ATLAS: CANVAS PACKAGE

1. In Canvas, go to Files and upload Anatomy-Atlas.zip. When Canvas asks, choose to expand (unzip) it.
   That keeps the img and pdf folders in place, so every page finds its pictures.
2. Open the Anatomy-Atlas folder and click index.html. That is the atlas front page.
3. To link it from a module or page: add a File item and pick Anatomy-Atlas/index.html.
4. Test it once while logged in as a student view: open a chapter, flip a card, open a PDF.

Only students logged into your course can reach these files.
To update later, upload just the changed files into the same folders and replace when asked.
