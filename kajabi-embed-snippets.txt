HOW TO USE
  1. In Kajabi, add a Custom Code block where the tool should sit.
  2. Copy one block below, paste it in, save.
  3. Nothing else to configure. Each block carries its own height
     receiver, so several tools can share one Kajabi page.

WHAT THE RECEIVER DOES
  An iframe has a fixed height; the page inside does not. Every
  page on the course site posts its height to the parent as the
  content changes. The receiver listens and resizes the frame, so
  the tool never scrolls inside itself or gets clipped.

  It matches on the window the message came from rather than on an
  id, because the course site grew two id conventions and matching
  on the source is immune to both.

  A page has to be live on GitHub Pages before its frame shows
  anything. Anything not yet uploaded renders as a 404 in the frame.

   Matches on the window the message came from, not on an id,

  var f = document.currentScript.previousElementSibling;
  if(!f || f.tagName !== "IFRAME"){
    f = document.currentScript.parentNode.querySelector("iframe");
  }
  if(!f) return;
  window.addEventListener("message", function(e){
    var d = e.data;
    if(!d || d.type !== "resize" || !d.height) return;
    if(e.source !== f.contentWindow) return;   /* not our frame */

  }, false);
}());
</script>
